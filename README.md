Website Marketplace Toserba

Membangun website marketplace untuk toko serba ada (toserba) yang memungkinkan pelanggan menelusuri produk, memasukkan ke keranjang, dan melakukan pemesanan secara online. Penjual dapat mengelola produk dan stok lewat dashboard admin.

1. Peran: Full-stack developer (proyek kelompok)
   
3. Fitur utama:
a. Katalog produk dengan pencarian dan filter kategori
b. Keranjang belanja dan proses checkout
c. Login dan registrasi pengguna
d. Dashboard admin untuk kelola produk, stok, dan pesanan
e. Tampilan responsif di HP dan komputer

Skill yang dikaitkan: HTML, CSS, JavaScript, PHP, MySQL, Pengembangan Web,dan E-commerce.
